สูตรการแปลงหน่วยอุณหภูมิ

อ้างอิงบทเรียนวิทยาศาสตร์ ม.1

สูตรแปลงหน่วยอุณหภูมิหลัก
$$\frac{C}{5} = \frac{F - 32}{9} = \frac{R}{4} = \frac{K - 273}{5}$$
แปลงระหว่าง Celsius และ Kelvin (°C ↔ K): K = C + 273 หรือ C = K - 273
C = องศาเซลเซียส (°C)
F = องศาฟาเรนไฮต์ (°F)
R = องศาโรเมอร์ (°R)
K = เคลวิน (K)
💡 การเปลี่ยนอุณหภูมิ ($\Delta T$): คำนวณจากผลต่างระหว่างอุณหภูมิหลังเปลี่ยน กับอุณหภูมิเริ่มต้น ($\Delta T = |T_2 - T_1|$)
